RapidRoute Analytics

RapidRoute Analytics is a data analytics project that studies delivery operations in quick commerce systems. The goal of this project is to analyze delivery data and understand the factors that affect delivery time and delays.

The project uses SQL for storing and querying the dataset and Python for data analysis and visualization. Different delivery metrics such as order time, delivery time, distance, and traffic conditions are analyzed to identify patterns in delivery performance.

A machine learning model is also used to predict the probability of delivery delays based on factors like distance, traffic level, and order time. This helps in understanding which conditions are more likely to cause delivery delays.

An interactive dashboard was developed using Streamlit to display important insights such as delivery trends, peak demand hours, and delay patterns.

Technologies Used
- Python
- SQL
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

Project Goal
The objective of this project is to demonstrate how data analytics can be used to improve delivery efficiency and understand operational patterns in quick commerce systems.
